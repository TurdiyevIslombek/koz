# Public judge clip

`orange-red-ball.mp4` is an 18-second, 320 × 240, 10 fps drawing generated by
`scripts/make_judge_clip.py` with OpenCV. It contains one orange-red ball on a grey
stage, no people, no camera footage and no audio. It is original project material
under the repository's MIT licence and is under 2 MB.

The ball keeps the same colour throughout (BGR 0, 110, 255 before compression).
The default red range misses it. The agent measures the hue, adjusts
`color_finder.hue_center`, tests again and detects it. All privacy and face-blur
checks stay enabled with the real models. This demonstrates adaptation on drawn
input; it is not evidence of accuracy on real people, rooms or the robot.

Run `bash scripts/judge_demo.sh` from the repository root. To regenerate the clip
after installing the pinned dependencies: `.venv/bin/python scripts/make_judge_clip.py`.
